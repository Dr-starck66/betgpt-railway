# ASTRA NATIONAL BREAKOUT Ω

BetGPT growth operating system.

It joins the existing analytics, Discover, sharing and affiliate systems into one measurable loop:

1. Acquisition
2. Activation
3. Retention
4. Virality
5. Revenue

The server compares the latest 24 hours with the previous 24 hours, scores the growth state and returns the three highest-priority actions.

## Surfaces

- Admin cockpit: `/admin/growth`
- Machine-readable production endpoint: `/api/national-breakout`
- Hourly cloud evidence: `.github/workflows/astra-national-breakout.yml`

## Rules

- UNKNOWN stays UNKNOWN; missing traffic is never fabricated.
- Weak business metrics are not release failures.
- Broken measurement, endpoint or scoring code is a release failure.
- National Breakout is included in ASTRA Never-Fail candidate validation.
- Discover readiness uses the existing fail-closed editorial quality gates.
- Affiliate performance is measured from actual tracked outbound clicks.
- Recommendations are ranked from observed data rather than guessed search volume.

## Current growth loops

- Acquisition: visits + 24h momentum + Discover-ready inventory.
- Activation: chat, match analysis and Score Hunter actions.
- Retention: measured return visits.
- Virality: page/chat share events.
- Revenue: tracked bookmaker outbound clicks.

Future connectors such as Search Console can enrich the acquisition loop without changing the core contract.
